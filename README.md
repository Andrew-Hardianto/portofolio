# Andrew Hardianto - Personal Portfolio

![Portfolio Preview](./src/assets/react.svg) *(Built with React & Vite)*

Welcome to the source code of my personal portfolio website! I am **Andrew Hardianto**, a Front-End Developer (Mobile & Web) with experience in building stable, scalable, and user-oriented digital solutions. 

This website was built to showcase my professional experience, skills, and featured projects. It features a modern, clean, and responsive design with soft-light neumorphic (glassmorphism) aesthetics.

## ✨ Features

- **Modern UI/UX**: Soft light theme featuring subtle shadows, glassmorphism panels, and smooth blur-blob accents.
- **Fully Responsive**: Optimized for both desktop and mobile browsers.
- **Interactive Project Showcase**: A dynamic grid of projects with a detailed pop-up modal for each.
- **Single Page Application**: Fast navigation using React functional components.

## 🛠️ Technologies Used

- **React.js** (Functional Components, Hooks)
- **Vite** (Next Generation Frontend Tooling)
- **Vanilla CSS** (Custom CSS Variables, Flexbox, CSS Grid, Animations)

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps:

### Prerequisites

- Node.js installed on your machine
- npm (Node Package Manager)

### Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/Andrew-Hardianto/portofolio.git
   ```
2. Navigate to the project directory:
   ```sh
   cd portofolio
   ```
3. Install the dependencies:
   ```sh
   npm install
   ```
4. Start the development server:
   ```sh
   npm run dev
   ```
5. Open your browser and visit the URL provided in the terminal (usually `http://localhost:5173/`).
